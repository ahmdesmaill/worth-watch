# Worth Watch

## A movie website where you can search for movies & add them to your watchlist!

![A screenshot showcasing the website](./website-showcase.png)

### [Website link](https://ahmdesmaill.github.io/worth-watch/)

#### Technical details about the website:

- ✅ Saves movies in your browser's local storage so they're still available after closing the website
- 🎬 Uses the open movie database for its movies (OMDb)
- 💻 Made with plain client side HTML, CSS & JavaScript
